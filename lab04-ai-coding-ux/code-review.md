## รายละเอียด Review Comments

### 1. `add_product(self, product: Product)`
- **Category:** `correctness`
- **Severity:** `high`
- **ปัญหา:** ปัจจุบันใช้ `self._products[product.name] = product` โดยตรง หากมีการเพิ่มสินค้าที่ชื่อซ้ำกับของเดิม ข้อมูลสินค้าเดิมรวมถึงสต็อกปัจจุบันจะถูกเขียนทับหายไปทันทีโดยไม่มีการเตือน
- **แนวทางแก้ไข:** เพิ่มเงื่อนไขตรวจสอบว่ามีชื่อสินค้านี้อยู่แล้วหรือไม่ หากมีให้ raise ValueError:
  ```python
  if product.name in self._products:
      raise ValueError(f"Product '{product.name}' already exists")
